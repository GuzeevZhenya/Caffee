# Спринт 10 — боевой API и доставка

**Goal:** Mini App и сайт на Vercel ходят в тот же `/api`, что и локально. Гость оформляет доставку с адресом в зоне (центр Минска), бесплатно от 30 BYN, и видит статус заказа.

## В скоупе

1. Hono API как Node-функция Vercel (`/api/*`), Prisma generate на сборке.
2. `POST /api/orders` принимает адрес доставки, проверяет полигон и порог 30 BYN.
3. Checkout: тип «Доставка», форма адреса, геолокация, статус после оформления (в т.ч. вкладка Mini App).

## Вне скоупа

- Railway / отдельный хост API.
- JPG-топпинги тирамису (хватает SVG).
- Realtime `editMessageText` в чате бота (5.3).
- Supabase Storage для фото админки на serverless.
