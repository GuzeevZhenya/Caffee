# Фаза 5 — Telegram-бот

**Goal:** Гость в Telegram оставляет имя и телефон, проверяет зону доставки, следит за заказом и за 15 минут до брони даёт бариста сигнал «готовить сейчас».

**Срез 5.1 (эта сессия)**
1. `/start` — контакт (имя + телефон), запись профиля через API
2. Геолокация — полигон из `@repo/shared`, доставка бесплатно от 30 BYN
3. `/status` — статус по номеру заказа, кнопки триггера при `COOKING_HOLD`
4. Напоминание за 15 минут до слота брони (`Booking.reminderSent`)

Бот ходит только в `apps/api`, без `@repo/database`.

**Вне скоупа 5.1:** заказ из чата, оплата, полноценный TMA UI, realtime-плашка, живой Supabase (спринт 08).
