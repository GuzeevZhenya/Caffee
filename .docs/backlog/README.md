# Backlog — что не успели / доделать позже

Сюда записывай всё, что нужно доделать: правки дизайна, идеи, недочёты, новые фичи.
По одному пункту на строку (или списком) — при продолжении работы разберу по порядку.

## Формат
- [ ] что сделать — где (страница/компонент) — комментарий (необязательно)
